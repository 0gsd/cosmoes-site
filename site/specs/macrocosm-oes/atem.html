Comprise OES · comprise/1

a company: its concerns, their relationships, eight modules each

  • C Corporation — The legal body: ownership, contracts, filings, money: entity, bond, instrument, captable, contract, filing, licence, certification, charter, asset, segment, counterparty, policy, ip, governance, finance, event, aim
  • O Organizations — Roles, teams, seats and who decides: role, unit, position, chart, decision-right, decision

Checks

  • load — a file that does not parse, is not a mapping, or uses a forbidden construct (error)
  • duplicate-id — an id already loaded in the same module of the same part; the first wins (error)
  • id-grammar — an id that does not parse in the MiniCOSM's id form (error)
  • id-module — an id whose module the MiniCOSM does not declare, or, in a folder volume (error)
  • type — a missing type, or a kind the item's module does not declare (error)
  • type-prefix — an id whose kind disagrees with its type, outside the exception forms the manifest declares (error)
  • identity-min — a field the manifest's envelope.required lists that the item does not carry (error)
  • provenance — a provenance block missing where required, or malformed (error)
  • status — a status outside the status list (error)
  • visibility — a visibility outside the visibility list (error)
  • ref-grammar — a value in a named reference field that is not an id of a known… (error)
  • ref-unresolved — a reference that names nothing in the volume (error)
  • closed-list — a value outside its closed list, for any field the manifest's closed-lists names (error)
  • pending-shape — an open question whose question is empty or not a string (warning)
  • module-none — a module: none with no reason (warning)
  • catalog-key — a catalog key the manifest's catalog.keys does not list (a note) (error)
  • atem-shape — an item with no atem (error)
  • numbering — a section number used twice, one that skips or repeats among its siblings (error)
  • term-defined-once — a term the document defines more than once; the first definition is kept (warning)
  • unlinked-mentions — a paragraph that opens with a bold phrase the way a definition does (note)
  • empty-section — a heading with no body and no sections under it (note)
  • stale-provenance-hash — a generated item whose part of a manifest has changed (warning)
  • xref-unresolved — a reference across volumes that names nothing in its inventory (error)
