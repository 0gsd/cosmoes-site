Checks

  • load — a file that does not parse, is not a mapping, or uses a forbidden construct (error)
  • duplicate-id — an id already loaded in the same module of the same part; the first wins (error)
  • id-grammar — an id that does not parse in the format's id form (error)
  • id-module — an id whose module the format does not declare, or, in a folder volume (error)
  • type — a missing type, or a kind the item's module does not declare (error)
  • type-prefix — an id whose kind disagrees with its type, outside the exception forms the manifest declares (error)
  • identity-min — a field the manifest's envelope.required lists that the item does not carry (error)
